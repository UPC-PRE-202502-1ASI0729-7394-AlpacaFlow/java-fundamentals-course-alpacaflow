 01 – Introducción a Java

Java es un lenguaje de programación ampliamente utilizado en la industria gracias a su estabilidad, seguridad y capacidad de ejecutarse en distintos sistemas operativos sin modificaciones. Su filosofía “Write Once, Run Anywhere” permite que un mismo programa funcione en Windows, macOS o Linux mediante la Máquina Virtual de Java (JVM).

Aprender Java es una excelente forma de comenzar en el mundo de la programación, ya que combina claridad en su sintaxis con poder para construir aplicaciones reales como sistemas web, apps móviles para Android, software empresarial y aplicaciones de escritorio.

En este curso trabajaremos completamente en línea, utilizando editores como Replit o JDoodle, por lo que no será necesario instalar programas adicionales. A través de pequeños ejemplos prácticos, irás comprendiendo la estructura de un programa, cómo se ejecuta y cómo escribir tus primeras instrucciones en Java.

En esta lección veremos:

Qué es programar.

Qué es Java y para qué se utiliza.

Cómo luce un programa básico.

Cómo ejecutar tu primer “Hola, Java”.

Este primer acercamiento sentará las bases para comprender los conceptos fundamentales que exploraremos en las siguientes lecciones.
